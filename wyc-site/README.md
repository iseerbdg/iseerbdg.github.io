# Wayzata Yacht Club Website Concept

A responsive, modern one-page homepage prototype for Wayzata Yacht Club.

## Open the site

Double-click `index.html` or place the folder on any static web host.

## Included

- Responsive desktop, tablet, and mobile layout
- Sticky navigation and mobile menu
- Racing, crew, learning, Apostle Islands, membership, and club-story sections
- Calls to action linked to the current WYC/Clubspot pages
- Accessible semantic HTML and reduced-motion support
- Local image assets; no build tools or frameworks required

## Content notes

The prototype draws from public information on WYC's official pages as reviewed August 1, 2026:

- https://www.wyc.org/about
- https://www.wyc.org/membership
- https://www.wyc.org/fleets
- https://www.wyc.org/crew
- https://www.wyc.org/seminars
- https://www.wyc.org/ais

Before launch, confirm current membership rates, event dates, contact names, URLs, and the preferred Clubspot integration.
